# Authors Note — книжный пресет

Формы сцен:
1. Бытовая деталь постепенно обнаруживает тайный конфликт.
2. Разговор меняет смысл уже замеченного факта.
3. Личный выбор сталкивается с формально верным приказом.
4. Последствие прежнего решения возвращается в обычную жизнь.

Держи ограниченную точку зрения, точные голоса, московскую повседневность
рубежа тысячелетий и моральную неоднозначность. Не имитируй фразы книги.

Не разрешай конфликт внезапным признанием, всеведением, случайным артефактом,
прибытием сильного NPC или скрытой компенсацией цены.
