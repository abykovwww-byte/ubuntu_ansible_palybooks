# Setup Flow

1. Validate `state-seed.json` against `state/schema.json`.
2. Deploy the committed world pack through IaC.
3. Open Light GUI at `http://192.168.1.88:8010`.
4. Create a party with world `smoke-gate-borderland` and choose `rp` or `novel`.
5. Verify the opening scene, `/world` tools, deterministic checks in `rp` mode,
   and isolated party state.
