# Quick Reply Notes

Use the existing `RP World` preset generated by the stack when available.

## World Buttons

- `Мир`: opens an input box and sends `/world <instruction>` to the gateway.
- `Применить мир`: sends `/world apply latest`.
- `Отменить preview`: sends `/world discard latest`.
- `Показать мир`: sends `/world show`.
- `Откат мира`: sends `/world rollback`.

```text
Запомни: Илья Сорн показал игроку различие между архивным воском и серым воском с письма.
Запомни: Мара Вей разрешила игроку допросить ночной караул, но закрытый журнал пока не дала.
Запомни: Тамар Арел потребовала две монеты за имя покупателя поддельного пропуска.
Запомни: Сава Девять Меток согласен на встречу у Черноводной пристани после полуночи.
```

## Check Shortcuts

Create optional custom Quick Replies for common checks if you want faster play:

```text
/check information target=ledger-archive skill=2 difficulty=11 goal="проверить печати и архивный воск"
/check persuasion target=mara-vey skill=1 difficulty=13 goal="получить ограниченный доступ к журналу Стражи"
/check resource resource=coin amount=2 difficulty=8 goal="заплатить за безопасную встречу"
```

Do not apply world changes automatically after preview. Let the gateway show the pending patch, then confirm with `Применить мир`.
