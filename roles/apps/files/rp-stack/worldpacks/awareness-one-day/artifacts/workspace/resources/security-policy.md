# Краткая политика информационной безопасности

1. Используйте корпоративные учётные данные только на проверенных ресурсах.
2. Не включайте активное содержимое в файлах из непроверенных источников.
3. Подозрительные письма, ссылки и файлы передавайте специалистам ИБ через штатный канал.
4. Не пересылайте подозрительные материалы коллегам и не публикуйте их во внешних сервисах.
5. При сомнении подтвердите запрос через независимый известный канал связи.

Это учебный публичный документ WorldPack. Реальная политика может заменить его как IAC-managed ресурс с сохранением стабильного blueprint ID.
