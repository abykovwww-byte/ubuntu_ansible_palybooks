# Quick Replies: Инцидент-50

Suggested Light GUI / SillyTavern helper buttons for this world. Do not overwrite global presets while creating the source worldpack.

```text
Показать state
/world show

Черновик факта
/world Remember:

Применить факт
/world apply latest

Сбросить черновик
/world discard latest

Проверка: информация
/check information target= skill=2 difficulty=12 goal=""

Проверка: feasibility
/check feasibility target= skill=2 difficulty=12 goal=""

Проверка: убеждение
/check persuasion target= skill=2 difficulty=12 goal=""

Проверка: ресурс
/check resource resource=analysis-bandwidth amount=1 difficulty=12 goal=""

Брифинг штабу
Сформулировать короткий статус для кризисного штаба: подтвержденные факты, версии, риски, следующее решение.

Сохранить доказательство
Зафиксировать артефакт в chain-of-custody и объяснить, какую версию он подтверждает или опровергает.

Счетчик 50 ходов
Напомнить текущий номер хода, оставшиеся ходы и ближайший сценарный дедлайн.
```
