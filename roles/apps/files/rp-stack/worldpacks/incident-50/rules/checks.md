# Checks: Инцидент-50

Use gateway checks when the outcome is uncertain, resisted by an NPC, changes canonical state, affects evidence integrity, changes containment, alters public/client communication, or assigns responsibility.

## Suggested Check Types

- `information`: сопоставить логи, построить временную линию, проверить гипотезу, отличить шум от сигнала, оценить фрагмент «доказательства».
- `feasibility`: оценить план containment, восстановление из бэкапа, клиентскую коммуникацию, законный контакт с подрядчиком.
- `persuasion`: убедить IT, правление, юристов, PR или внешнюю IR-команду принять аккуратный план.
- `trust`: добиться честного разговора с Ильей, Олегом, Павлом, Мариной или Никой.
- `deception`: использовать только для защитных легенд внутри легального расследования, например не раскрывать атакующему лишнюю реакцию; не применять для незаконного обмана.
- `resource`: потратить время команды, окно обслуживания, бюджет внешней IR, внимание руководства, доверие клиентов.
- `stealth`: скрытно наблюдать в собственных системах, не выдавая атакующему defensive-реакцию; не означает незаконный взлом чужих систем.
- `conflict`: спор в штабе, жесткая дискуссия с руководством, кризис доверия между ИБ и IT.
- `intimidation`: допустимо как профессиональное давление внутри полномочий, например остановить опасное распоряжение ссылкой на протокол; не шантаж и не угрозы.

## Example Chat Commands

```text
/check information target=siem-telemetry skill=3 difficulty=12 goal="отделить связанные события атаки от фонового шума"
/check feasibility target=primary-dc skill=2 difficulty=13 goal="оценить цену частичной изоляции складского контура"
/check persuasion target=oleg-shumilov skill=2 difficulty=12 goal="согласовать сохранение артефактов перед изменениями в проде"
/check trust target=ilya-safonov skill=2 difficulty=10 goal="получить честный рассказ о раннем алерте без поиска виноватого"
/check resource resource=analysis-bandwidth amount=1 difficulty=12 goal="подготовить чистую выгрузку для внешней IR-команды"
/check conflict target=executive-committee skill=2 difficulty=14 goal="защитить containment-план от требования восстановить все немедленно"
/check information target=attacker-pressure-channel skill=3 difficulty=14 goal="проверить фрагмент данных без признания его достоверности"
```

## Difficulty Guide

- 8: обычная рабочая задача при ясном доступе и низком риске.
- 10: задача с ограниченным временем или одним сопротивляющимся NPC.
- 12: важное решение с бизнес-ценой, неполными логами или заметным риском ошибки.
- 14: кризисная сцена с давлением руководства, юридическим риском или угрозой потери доказательств.
- 16: сильная неопределенность, высокий ущерб, конфликт фракций или почти истекший дедлайн.
- 18: финальные решения последних ходов, где цена ошибки меняет концовку.

## State Rules

- Утечка данных не подтверждена, пока state не содержит подтвержденный факт с источником.
- Активный доступ атакующего не подтвержден только сообщением «Рубина».
- Павел Меньшов не виновен без артефактов, интервью или иных подтвержденных state updates.
- Бэкап не считается чистым без проверки и state update.
- Сильное containment-решение должно фиксировать цену для uptime, доверия или доказательств.
- Коммуникация клиентам должна различать подтвержденные факты, вероятные факты и неизвестное.
- Повторная попытка требует новой информации, ресурса, союзника или измененной ситуации.

## Cyber Safety Rules

- Не генерировать команды, вредоносный код, фишинговые тексты, реальные индикаторы для атаки, инструкции обхода защиты или эксфильтрации.
- Можно описывать defensive-артефакты обобщенно: временная линия, хэши как placeholders, группы событий, журналы, сетевые зоны, статусы EDR.
- Если игрок просит offensive-путь, результатом проверки должно стать законное defensive-направление или блокировка по hard constraint.
