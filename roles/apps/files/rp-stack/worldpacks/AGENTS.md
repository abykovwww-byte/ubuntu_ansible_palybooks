# WorldPack instructions

- WorldPack files define immutable authored content; Gateway remains the runtime authority.
- Route RP packs through `rp-world-pack-builder`; route scored learning scenarios through `training-world-pack-builder`.
- Training outcomes must remain deterministic and evidence-based. Model prose cannot award scores or invent browser interactions.
- Validate state seeds, referenced files, schemas, turn schedules, links, artifacts, workspace policies, scoring, and debrief contracts before publishing.
- Existing runs must remain pinned to their materialized revisions; do not retrofit historical turns from edited files.
