# RP Light GUI

The UI is a thin client for the single Decision 043 RP runtime. It supports
World/Scenario Party creation, exact Narrator retries, Party history, role
status, owner-reviewed Lore and PlayerCorrection operations, Administrator
proposals, and Party-scoped OpenRouter BYOK.

There is no legacy/revision switch, check/D20 flow, autotest control, fallback
route, or destructive Party-data action in this client.
