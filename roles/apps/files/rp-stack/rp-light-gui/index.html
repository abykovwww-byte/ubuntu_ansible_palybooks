Партия

Связка

Что именно сейчас соединено в одну партию: мир, персонаж, модель и отдельный state.

Состояние

Каноничные факты партии. GM не должен менять их без проверок или world edit.

Персонажи

Карточки игрока и заметных NPC из structured state: статус, отношения, обязательства, нитки и последнее появление.

Контекст

Фактический prompt предыдущего запроса: state, правила и прямое окно истории из записанного Gateway prompt_json.

Prompt inspector

Без текста открывает фактический предыдущий prompt. Если в поле хода есть текст — собирает безопасный dry-run и показывает, почему вошли главы, raw-история и retrieval.

Память

Долгая память для модели: сжатые старые ходы, подтвержденные факты, открытые нити и изменения отношений. State напрямую не меняет.

Lore Cards

Только ваши подтвержденные заметки. Карточка помогает retrieval, но не становится canonical state.

Checkpoints

Безопасный снимок state, покрытия памяти и активных карточек. От checkpoint можно создать изолированную ветку внутри партии; основная линия не изменяется.

Режим GM

Безопасные правки мира: сначала preview, потом явное применение.

Проверка

Быстрый /check: gateway решает исход, а модель только описывает его как сцену.

Управление

Операции над текущей партией. Миры и персонажи не удаляются этой кнопкой.

BYOK

Личные ключи для модели ведущего. Каждый ключ принадлежит только выбранной сейчас партии и никогда не используется в других партиях или служебной моделью.

Автотест · LLM против LLM

Только для администратора. Gateway создаст отдельную ветку от checkpoint активной партии; основная линия не изменяется.

Глобальные настройки

Служебная модель

Служебная модель — единая глобальная LLM для долговременной памяти, изменения мира и генерации персонажей. Администратор выбирает её один раз для всего RP Stack: для всех текущих и будущих партий всех пользователей. Она не ведёт партию и не использует партийные BYOK-ключи.

Датасет LoRA / QLoRA

Сырые ходы сохраняются всегда, но в JSONL попадут только партия и ходы со статусом «Одобрено». Перед одобрением проверьте качество, персональные данные и fallback.

Миры-пресеты

Приватные миры видны только администраторам и недоступны в ShowRoom.
